# Snoopzy — Competitor Notes

Based on the products' own websites (Oct 2026). The apps themselves were not tested.

| | ShadowHunt | Manhunt | Snoopzy (planned) |
| --- | --- | --- | --- |
| Platform | Browser; Android "coming soon" | iOS and Android | Android first |
| Modes | Hide and seek style, 30-min matches | One mode: manhunt / tag | Hide and seek with shrinking zone; more modes later |
| Roles | Basic | Seeker and hider; hiders can tag seekers back | Seeker, hider, plus secret twist roles |
| Zone | Shrinks every 10 min | Owner-drawn circle or polygon; safe and capture zones; moving zones in Pro | Phased shrinking rings |
| Tagging | Tap to confirm | Seeker tags, hider confirms | GPS hold-to-tag, 5 s, accuracy checks |
| Proximity | GPS pings every 3 min | GPS plus Bluetooth for "within 30 ft / 100 ft" display | GPS first; Bluetooth or UWB only if disputes appear |
| Abilities | None noted | Immunity shield, ability drops | 2 revive shields per player |
| Social | Discord community (about 8.5k members in 2 days) | Group chat, voice memos, polls, anonymous messages | Lobby text chat; recap; voice later |
| Joining | Link | Invite code | Room code |
| Pricing | Free | Free, optional Pro subscription | Free for now |

## Takeaways

- Invite codes, live map, zones, shields and chat are now standard, so they will not set Snoopzy apart.
- Snoopzy's edge is the round design: shrinking zone, secret roles, revive shields and the end-of-round recap.
- Tap-to-confirm tagging is easy to dispute; the 5-second hold rule is stricter and fairer.
- Manhunt uses Bluetooth for proximity display, not tag proof, which supports keeping it as a later upgrade.
